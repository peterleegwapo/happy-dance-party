# Happy Dance Party v2

## Features
- One public lobby only; automatic room allocation, up to 30 players per room
- Real-time movement, chat, player list, mobile joystick
- 12 dance actions: bounce, spin, wave, groove, heart, clap, moonwalk, robot, hiphop, jump, cheer, idle
- Character customization: outfit color, four hairstyles, four skin tones, four outfit styles, accessories
- Original synthesized electronic dance beat using the browser Web Audio API (no copyrighted recording included)

## Deploy
- Build command: `npm install`
- Start command: `npm start`
- Node 18+

Music starts after the player taps the play button because browsers require a user gesture for audio.
